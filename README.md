A Python project that combines machine learning and web scraping to collect soccer match data, analyze player performance, and automatically group and categorize match scores based on player metrics.

**Features**

Web scraping tools to fetch live and historical soccer data
Machine learning models to cluster and classify player performance
Score grouping and performance-based categorization
Data visualization with matplotlib / seaborn
Export results to CSV/Excel for further analysis

**Use cases**

Performance analysis of players and teams
Match insights for scouting or coaching
Data-driven soccer analytics projects
